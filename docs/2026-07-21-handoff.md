## Decisions locked 2026-07-21 (don't re-litigate)

- Triage skill is the faithful, generic port of the asking discipline (content depth + chunked reviews).
- Decision options: **Apply / Skip — decide later / Drop / Auto-resolve rest.**
  - **Skip — decide later** = not now; the item stays open; revisit later. (The "defer" disposition.)
  - **Drop** = explicit discard.
  - The harness Skip button records the *misleading* `[No preference]` — treat it as **decide later**,
    never "you pick"; always offer an explicit **Skip — decide later** option to sidestep the ambiguity.
- **Comparing alternatives** = pros/cons depth + `Option | Pros | Cons | Best when` table + an
  optional weighted decision matrix + the decisive trade-off + a recommendation. The matrix is an
  *addition*, never a replacement for the pros/cons.
- **Commit-before-review** lives in `skills/_shared/review-loop.md` step 1, with a pointer from `triage`.
- **Finish = keep the repo local** (publish later).
