# AGENTS.md — claude-workflow

## Docs convention

- Specs/designs → `docs/specs/YYYY-MM-DD-<slug>.md` (no counter, no `-design` suffix)
- Plans → `docs/plans/YYYY-MM-DD-<slug>-plan.md`

Skills that default elsewhere must honor this. `superpowers:brainstorming` and
`superpowers:writing-plans` both defer to user preferences for location.

## Public repo — no personal data

This repo is public. Do not write personal or medical detail about the maintainer or
contributors into any committed file. Describe working preferences neutrally instead
(e.g. "the person prefers low cognitive load and drives decisions themselves").
